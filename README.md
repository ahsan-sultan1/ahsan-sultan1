## 🤖 Featured project: Codev AI

**Codev AI** is an AI debugging extension for VS Code that I founded and built. It is live on the Marketplace.

- Detects errors automatically as you code and explains the **root cause** in your own language (50+ languages supported)
- **One-click Apply Fix** that patches the file directly
- AI code review on save, chat assistant, and code explain on selection
- Remembers recurring bugs and shows a local analytics dashboard
- Built with **TypeScript**, the **VS Code Extension API**, and **Groq (Llama 3.3 70B)**

👉 [Install Codev AI](https://marketplace.visualstudio.com/items?itemName=AhsanSultan.codev-ai) • [Join the Discord](https://discord.gg/KV5fmRq5HV)
